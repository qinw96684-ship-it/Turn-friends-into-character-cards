# 聊天记录蒸馏提示词

把一段真实聊天记录，压缩成两个可直接注入 AI 的文件：**核心.md**（常驻人格层）+ **任务卡.md**（AI 工作说明书）。

## 文件说明

| 文件 | 内容 |
|---|---|
| `蒸馏提示词.md` | 操作手册。八个步骤，从数据检查到迭代。 |
| `蒸馏失败案例库.md` | 四次真实失败的完整记录。**建议开始前先读。** |

## 核心理念

这套方法能**描述**人，不能**预测**人。

验算机制最大的价值不是证明文件准，而是测出文件的能力边界在哪。

## 快速开始

1. 先读 `蒸馏失败案例库.md`
2. 按 `蒸馏提示词.md` 的第负一步判断数据是否够用
3. 数据 ≥1000 条走完整流程，500-1000 条走降级版
4. 第二部分（效果配对）是最关键的一步，不要跳

## 已知边界

- 描述能力 ✅ / 预测能力 ❌
- 样本量 <30 条时，任何百分比都是噪声
- 分类必须带上下文，关键词匹配会出错
